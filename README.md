
# CopiMon

Videojuego de combate por turnos desarrollado en Python
utilizando Pygame.

## Características

- Tres monstruos: Axongor, Ruppira y Bryocut.
- Cuatro movimientos por monstruo.
- Sistema de prioridades y velocidades.
- Habilidades especiales, críticos y quemaduras.
- Inteligencia artificial básica.
- Menús de selección y pantallas de resultados.

## Instalación

Instalar las dependencias:

```bash
python -m pip install -r requirements.txt
```

Ejecutar el juego:

```bash
python main.py
```

## Controles

- Ratón: seleccionar monstruos y movimientos.
- Botón MENÚ: regresar a la pantalla principal.
